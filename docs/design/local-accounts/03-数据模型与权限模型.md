# 03 · 数据模型与权限模型

## 1. 与 EasyAuth 模型的映射

| EasyAuth | 本地对应 | 决策 |
|---|---|---|
| App | 宿主自身（app_key） | 不变 |
| Permission + PermissionGroup 树 | 单一权限注册表 → catalog；`group_key` 点号隐式树 | D1 / D3 |
| AppScope（SELF/MANAGED_USERS/ALL） | grant 携带 scope；MANAGED_USERS 不可授本地用户 | D2 |
| AuthorizationGroup（role/bundle） | 无——不做本地角色层 | D5 |
| AccessGrant 版本化 | `local_grants_version` 自增 + 必填 CAS | D6 |
| grant 级 expires_at | 不做；做**账户级** `expires_at` | D12 |

**本地可授集合 ⊆ 宿主目录**：active ∧ scope 交集非空（`supported_scopes ∩ {SELF, ALL}`）∧ 非 baseline ∧（操作者非超管时再排除 high）。≡ 关系不成立，目录是上界不是等集。

## 2. 表结构：现状（v1）与目标（v2）

`platform_accounts` 现状字段：`id(UUID PK)`、`username(unique)`、`email`、`avatar_url`、`ui_locale`、`password_hash?`、`external_source?`+`external_user_id?`(联合唯一)、`active`、`is_admin`、`must_change_password`、`local_permissions(JSON, [])`、TOTP 三字段、`sessions_revoked_at`、`created_at`。

v2 新增（0004 迁移）：

| 字段/约束 | 定义 |
|---|---|
| `local_grants_version` | `int NOT NULL DEFAULT 0` |
| `expires_at` | `timestamptz NULL`（NULL=永久；仅本地非超管行可非空） |
| CHECK 三态约束 | `external_source IS NULL OR (password_hash IS NULL AND is_admin = false)` |
| catalog 表 `group_key` | `text NULL`，读取回落 `domain` |
| catalog 表 `risk_level` CHECK | `IN ('standard','high')`；代码侧 `Literal`；存量非法值（如 Customs 的 `medium`）迁移前归一，读取遇未知值按 `high` 处理（fail-closed） |

其余表（catalog、snapshots、audit_logs、passkeys、settings、descriptor_keys）结构不变。

## 3. 本地 grant

### 3.1 形态与约束

统一 DTO `LocalGrant = {code, scope}`，用于 POST/PUT 请求与 detail 响应。写入校验（违者 422）：

1. `code` ∈ active catalog；
2. `scope` ∈ 该 code 的 `supported_scopes ∩ {SELF, ALL}`；
3. 同一 code 仅一条——**载荷含重复 code（无论 scope 异同）即 422**，不做静默去重；
4. baseline code 写入前剥离（隐式专属，不落库）；
5. 操作者非超管时，diff 中**新增或移除**任一 `high` code 即 422（D10，按前后差集校验而非仅入参）。

### 3.2 读取归一化

每次解析将存量 grants 对当前 active catalog 归一：未知/停用 code、scope 越界（`supported_scopes` 收缩后）、格式坏行一律剔除。目录变更即时生效，无需重写行。

### 3.3 版本

`local_grants_version` 在 `local_permissions` 发生**任何**变更时 +1（PUT 授权、PATCH 升超管清空 grants 等）。PUT 必须携带 `expectedVersion`，服务端 CAS，不匹配 409。

## 4. 账户有效期（D12）

- `expires_at`：带时区 ISO-8601 瞬时值；POST/PATCH 拒绝过去时间（422）；
- PATCH 三态：字段缺省=不变，`null`=清除，值=设置；
- `expired := expires_at != null ∧ expires_at <= serverNow`（服务端时钟）；
- 到期效果由统一资格判定承载（02 §4）：登录拒绝**且存量会话下一请求即失效**；
- 守卫：**超管账户禁止设置 `expires_at`**（422，从根上排除"最后管理员过期"）；任何人不可设置/修改自己的有效期（403）。最后管理员判定 = active ∧ 未过期 ∧ 本地 ∧ is_admin 计数（行锁下）。

## 5. 迁移 0004

- 内容：§2 全部新列/约束 + `local_permissions` 元素就地升级 `"code"` → `{"code", "scope": <该 code supported_scopes 最大可用>}`。
  - EasyFrame 存量可授 code 全部单 scope `[ALL]`，升级是恒等变换；
  - EasyCustoms 是唯一有 v1 存量的下游，同规则转换（07 §2）。
- **部署栅栏**：全生态单副本，且迁移在应用启动前由 `run.py` 执行（老进程先停、迁移、新进程起）——不存在混合版本读写窗口，无需 expand/contract。
- 降级：downgrade 把对象元素还原为 code 字符串、删新列，老代码可直接运行。
- 列类型保持 SQLAlchemy `JSON`；不承诺 JSONB 包含查询（量级 ≤60×O(10)，应用层过滤足够）。
