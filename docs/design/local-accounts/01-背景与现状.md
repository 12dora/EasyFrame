# 01 · 背景与现状

## 1. 需求

| # | 需求 | 现状 |
|---|---|---|
| R1 | 超管可 CRUD 本地用户 | v1 已落地（EasyFrame blank host） |
| R2 | 密码自定义或点击生成；超管可改密 | v1 已落地 |
| R3 | 超管为本地用户授权，权限分类同 EasyAuth | v1 为 code 级授权；scope/风险/委派边界由 v2 补齐 |
| R4 | 引入 EasyTrade / EasyCustoms / EasyProject | 未完成，本设计主体工作（见 07） |

"引入 app" = 各下游宿主启用本地用户能力：各 app 超管在自己 app 内建本地用户、按该 app 自己的权限目录授权。本地用户 per-app，不跨 app 共享（D8）。框架站是被各 app 以 submodule 内嵌的底座，不是聚合门户。

## 2. 现状事实（对照代码核实）

### 2.1 认证三通道

1. **本地密码登录**：`POST /api/v1/auth/login`，bcrypt + 可选 TOTP/passkey；受 `BLANK_LOCAL_AUTH_MODE` 控制（现状四态，生产默认 `disabled`；v2 改五态，见 04 §4）。超管由环境变量首次 seed 进 `platform_accounts`，强制首登改密。
2. **Authentik OIDC**（code+PKCE S256+nonce）：登录后按 `external_source='authentik' + sub` upsert 账户行并拉 EasyAuth 权限快照。
3. **可信上游 principal**（网关注入 JWT 头），同样 upsert 为 authentik 来源。

会话 = 自签 HS256 JWT（8h，按用途派生子密钥，`sessions_revoked_at` 水位线吊销），前端 localStorage + Bearer。

### 2.2 权限解析现状

```
本地超管   → ALL_PERMISSIONS
本地普通   → BASELINE_SELF_SERVICE ∪ (local_permissions ∩ active catalog)
外部身份   → EasyAuth 快照 normalize 后集合（有效期以上游 expires_at 为准，过期即空）
```

注意：目前 `ALL_PERMISSIONS`（`adapters.py:102`）与 `FRAMEWORK_PERMISSIONS`（`authz_api.py:65`）是**两份独立硬编码集合**，"单一事实源"尚未成立——v2 必须收敛为一个宿主权限注册表并加防漂移测试（02 §2）。

### 2.3 v1 已有能力（契约 `docs/LOCAL_ACCOUNTS.md`）

`/api/v1/local-accounts` CRUD、code 级授权、超管重置密码、TOTP 救援、可授目录接口；门禁 `accounts.local.view/manage`；自我操作与最后管理员守卫；前端 EasyUI surface `enterprise-local-accounts`（antd）+ blank host `settings/accounts` 页；契约测试 `platform_tests/test_local_accounts.py` + Playwright。

## 3. 下游现状（2026-08-11 对照仓库核实）

| 宿主 | 本地账户现状 | 关键差异 |
|---|---|---|
| EasyProject | `local_admin_accounts` 表，**所有本地账户合成为全权限超管**（`LocalAdminAuthzService`），无 grants/expiry 字段；无 `*_LOCAL_AUTH_MODE`（seed 走 provisioning 脚本） | 需账户模型改造迁移，不是"加列"能解决 |
| EasyTrade | `users` 表；seed 用 `EASYTRADE_SEED_ADMIN_PASSWORD` + 运行环境门控；manifest 由 S0 route-matrix 管道生成、版本自动推导 | 未接线 local-accounts |
| EasyCustoms | **已有 v1 `local_permissions` 列**（迁移 `0014_account_local_permissions.py`）与 ORM 映射——唯一存在 v1 存量的下游；manifest 是静态 descriptor（schema_version=1，无 auto-push）；权限注册表含 `medium` 风险值 | 需 list→object 数据转换 + 风险值归一 |

三宿主均未挂载 local-accounts router、均无前端管理页。`platform_tests/test_local_accounts.py` 直接 import `blank_app`，**当前无法参数化验证任何下游宿主**。

## 4. 差距分析（决策均已定案，见 08）

| 差距 | 定案 |
