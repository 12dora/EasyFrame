# 05 · 前端设计

## 1. 分层与复用

| 层 | 位置 | 说明 |
|---|---|---|
| Surface | EasyUI 子路径导出 `@easy-enterprise/ui/enterprise-local-accounts`（antd） | 一份实现全宿主复用；不从 `./enterprise` 主入口 re-export（无 antd 宿主不被拖入）；antd 为 optional peerDependency，宿主 pin `6.5.2` |
| 宿主页面 | 各 app 设置/后台区（路径各异，见 07 §3） | 壳：挂 surface，传 `adapter / labels / capabilities / locale` |
| Adapter | 宿主 `local-accounts-adapter.ts` | 映射到 `/api/v1/local-accounts`，走宿主自己的请求封装 |
| 导航 | 宿主 shell NavModel | 条目门禁 `accounts.local.view`，无权限不渲染 |

**能力驱动**：surface 的 `capabilities` 来自 `/auth/me` 的服务端派生字段（`isLocalSuperadmin`、`accountId`），不得从权限集合推断。控件规则：

- 非超管：隐藏 `isAdmin` 开关与有效期编辑；high 权限置灰；特权目标（isAdmin 或持 high grant）整行只读；
- 对 `accountId === 当前行`：禁用停用/降级/删除/改密/救援入口（后端 403 兜底）。

## 2. 页面结构

- **列表**：antd Table；徽标：超管 / 2FA / 已停用 / 待改密 / 已过期；`?search=` 过滤。
- **创建 Modal**：用户名/邮箱；密码框 + "随机生成"（`crypto.getRandomValues` 按策略生成，可再手改）；`mustChangePassword` 开关（默认开）；`isAdmin` 开关（开则隐藏权限选择器）；有效期日期选择（可选，默认永久）；权限选择器。
- **编辑 Drawer**：资料、启停用、升降超管（仅超管可见）、删除（confirm）、重置密码、TOTP 救援、有效期、权限编辑器。
- **一次性密码交接**：创建/重置**成功后**以专门回执弹层展示实际提交值 + 复制按钮，需显式确认后关闭；关闭/卸载即清组件态；密码输入用 `autocomplete="new-password"`；提示剪贴板不受应用控制。

## 3. 权限选择器

- 数据源 `GET /permission-catalog`；按 `groupKey` 点号层级分组（缺省回落 domain）；
- 每个勾选 code 旁出 scope 选择（选项 = `grantableScopes`；单选项时定死不出控件）；`grantableScopes` 为空的权限置灰注明"本地用户不可授"；
- baseline 权限锁定态展示（implied，不提交）；`riskLevel=high` 红标，非超管置灰；
- **复制授权**：从既有本地用户导入 grants 作初值（D5 的模板补偿）；
- 保存携带 `expectedVersion`（必填），409 → 提示"授权已被他人修改"并刷新。

## 4. i18n

权限名取 catalog 响应的 `nameZh/nameEn`；界面文案由宿主注入 `labels`（zh-CN/en 词表），surface 不内置。
