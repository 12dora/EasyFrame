# 06 · 安全设计

## 1. 原则

1. **fail-closed**：无快照/坏数据/过期 → 空权限；唯一例外：EasyAuth 快照 API 瞬时 503 时，**尚在有效期内的既有快照**可继续使用（上游契约明确 503 不得视为撤权）——过期或缺失仍是空权限。
2. **生产默认关**：`disabled` 是默认；常开走 `enabled` 档，`break_glass` 仅超管（04 §4）。正门与应急门分离后，break_glass 上的成功登录即告警信号。
3. **秘密不落地**：密码仅以 bcrypt hash 持久化；明文在请求内瞬时处理，**不持久化、不回显、不写日志/审计/缓存**；随机密码在浏览器生成。

## 2. 凭据与会话

| 项 | 机制 |
|---|---|
| 密码存储 | bcrypt；显式处理 72 字节截断（超长拒绝或预散列，实现时二选一并测试）|
| 密码策略 | 普通账户 8–128；**超管的改密与被重置沿用 bootstrap 强度（≥12 + 弱值黑名单）**，防止首登改密降级 |
| 认证时序 | 恰验一次 bcrypt hash（存在取真、缺失取 dummy），资格判定后置——无用户名枚举侧信道（04 §4） |
| 超管 seed | 逐模式后置条件见 04 §4；同名冲突行启动即炸 |
| 会话 | HS256 JWT 8h；`BLANK_JWT_SECRET` ≥32B 启动强校验；按用途派生子密钥；`_PREVIOUS` 轮换 |
| **跨宿主隔离** | 每宿主 JWT 根密钥必须唯一（07 checklist 项），JWT 绑定 `iss/aud` = 宿主 app_key 并在验签时校验——防止密钥复用/数据克隆导致跨 app token 重放 |
| 会话吊销 | `sessions_revoked_at` 水位线（改密/重置/TOTP 变更/passkey 增删/停用）+ **每请求资格判定**（02 §4）覆盖过期与模式收紧，无 8h 残留 |
| 二次验证 | TOTP（防重放 timestep）+ WebAuthn passkey；中间态不消耗失败额度 |
| 限流 | 全局 600/60s → IP 30/300s → 账号失败 10/300s；天然 per-app、per-账号。**已知限制**：进程内实现，仅单副本有效；宿主转多副本前必须先外置到 PG。本轮不改 |

## 3. 授权面守卫

核心是 04 §2 的操作者×目标矩阵 + 统一资格判定，本表列防御目标：

| 场景 | 守卫 |
|---|---|
| 委派者创建超管 / 授予或悄悄移除 high 权限 | 矩阵：isAdmin 与 high-diff 仅超管，422 |
| 委派者重置超管密码 / 清其 TOTP 实现接管 | 矩阵：特权目标一切变更仅超管，403 |
| 自我提权 / 自我救援绕过凭据证明 | 自我危险操作全禁（403），自助通道走 `settings/security` |
| 失管（删/停/降/过期最后管理员） | 最后管理员不变式按 active ∧ 未过期计数（行锁）；超管禁设有效期 |
| 目录收缩后存量 grant 残留 | 读取时归一化剔除（03 §3.2） |
| 未知 risk_level 绕过 high 规则 | Literal + DB CHECK；读取遇未知值按 high 处理 |
| 对 SSO 行走本地管理面 | 404，不泄露存在性 |
| 强制改密未完成即操作 | 全路由 403 `PASSWORD_CHANGE_REQUIRED` |
| 并发覆盖授权 | `expectedVersion` 必填 CAS；变更+审计同事务（unit-of-work） |

## 4. 审计与告警

- 变更审计动作名与登录事件见 04 §5；审计行与变更同事务。
- 告警规则：`break_glass` 模式下的 `auth.login.success`；登录模式发生切换（settings 变更审计）。
- 跨 app 审计聚合不在本设计范围。

## 5. 威胁模型摘要

| 威胁 | 评估 |
|---|---|
| 口令暴力破解 | 三级限流 + bcrypt + 可选 2FA；生产默认 disabled 暴露面为零 |
| 用户名枚举 | 单次 hash 时序均衡（§2）；409/404 文案不区分隐藏行 |
| 超管 env 泄漏 | 仅首次 seed 有效 + 强制首登改密（改密仍受超管强度策略） |
| token 窃取（XSS → localStorage） | **接受的已知风险，当前基本无缓解**：token 在 localStorage，生产 CSP 允许 inline script，同源代理不防同源 XSS。缓解路径（HttpOnly cookie + nonce CSP）列平台级 backlog，不在本设计范围 |
| 跨宿主 token 重放 | §2 跨宿主隔离（唯一密钥 + iss/aud） |
| 幽灵账户 | 账户级过期 + 已过期徽标可见可清理 |
| 滥用应急通道 | enabled/break_glass 分离 + break_glass 登录告警 |
| 误开本地登录 | 模式×RUNTIME_ENV 互斥启动校验；`make *-check` 门禁含真实登录链路 |
