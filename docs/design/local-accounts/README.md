## 核心不变式

1. **两条授权通路，互不合并**：本地授权与 EasyAuth 快照以 `external_source IS NULL` 硬分支；SSO 用户不可持有本地 grants（D4）。
2. **权限目录单一事实源**：宿主唯一权限注册表推导 manifest、catalog、超管全集与校验；本地可授集合是该目录经 scope/baseline/风险规则约束后的**子集**（D1）。
3. **统一资格判定**：本地账户的 登录模式 ∧ active ∧ 未过期 在密码认证、二次验证、会话签发与**每次已认证请求**上执行同一判定——模式收紧与账户过期即时生效，不存在 8h 残留窗口（02 §4）。
4. **操作者×目标矩阵**：创建/升降超管、授予或移除高危权限、对特权账户的一切变更仅超管可为；任何人不可对自己做危险操作；最后一个可用本地管理员（active ∧ 未过期 ∧ 本地 ∧ is_admin）不可失去（04 §2）。
5. **fail-closed**：快照过期即空权限；未知/停用/越界的 grant 读取时剔除；生产默认 `disabled`，常开须显式切 `enabled`（D11）。
